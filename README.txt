Lighting Advisor - installable web app (PWA)

1. Upload ALL files in this folder, keeping the icons/ subfolder, to any HTTPS web host
   (GitHub Pages, Netlify, Cloudflare Pages, or your company web server).
   HTTPS is required for offline mode and installation.
2. On iPhone, open the page in SAFARI (not Chrome), tap Share, then "Add to Home Screen".
3. Open it once while online. After that it works offline.
4. After editing any file, change VERSION in sw.js (for example to v2) so phones update.
